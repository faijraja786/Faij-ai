टेक्स्ट / फाइल हेल्पर

टेक्स्ट फाइल खोलें, शब्द गिनें, कॉपी या डाउनलोड करें।

इस single-file संस्करण में सामान्य text files (.txt, .md, .csv) का local reading समर्थित है। PDF/DOCX parsing और OCR शामिल नहीं हैं।

सेटिंग्स

अपना अनुभव और AI backend कॉन्फ़िगर करें।

महत्वपूर्ण: API key कभी इस HTML फाइल में न डालें। नीचे केवल अपने सुरक्षित backend का URL डालें। GitHub Pages पर public frontend में secret रखना सुरक्षित नहीं है।

AI backend connection

Backend endpoint को POST request पर JSON body जैसे {"messages":[{"role":"user","content":"..."}]} स्वीकार करना चाहिए और JSON में {"reply":"..."} लौटाना चाहिए। Streaming के लिए अलग implementation चाहिए।

डेटा और गोपनीयता

इस संस्करण में चैट, नोट्स, टास्क, क्विज़ हिस्ट्री और फ्लैशकार्ड इस ब्राउज़र के localStorage में रखे जाते हैं। ब्राउज़र डेटा मिटाने पर ये हट सकते हैं। अलग डिवाइस में sync नहीं होता।

इस संस्करण की स्थिति

काम करने वाले लोकल फीचर्स: टास्क, नोट्स, नमूना MCQ, फ्लैशकार्ड, vocabulary list, calculator, text utilities, code preview, text file helper, theme, export/import-जैसा JSON export।

अलग backend/service की जरूरत: वास्तविक AI chat, live web search, voice AI, image understanding, PDF/DOCX extraction, secure accounts/cloud sync, push reminders, official syllabus data.
